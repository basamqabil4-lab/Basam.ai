# BASAM Ai 01 — AI Prompt Generator

Web app for generating structured prompts for Infographics, Geographic Maps, Image-to-Prompt extraction, Backgrounds, and FHD/Broadcast scenes powered by Gemini 3.8 Flash.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Create `.env.local` and set your Gemini API key(s) (comma-separated supported for automatic rotation):
   `VITE_GEMINI_API_KEYS="YOUR_GEMINI_API_KEY"`
3. Run the app:
   `npm run dev`
